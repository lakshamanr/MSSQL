Implementation Details

Architecture

  • Frontend: Angular with reactive forms and RxJS
  • Authentication: OAuth2 Password Grant with JWT tokens
  • Token Storage: LocalStorage with automatic expiry management
  • Security: HTTP-only interceptor, route guards, automatic token refresh

Key Components

  • /login - Login page with form validation
  • AuthenticationService - Core auth logic and state management
  • TokenStorageService - Secure token storage and retrieval
  • AuthInterceptor - Automatic JWT token injection
  • AuthGuard - Route protection for authenticated pages
  • UserMenuComponent - User dropdown with logout

API Endpoints

  • POST /connect/token - OAuth2 token endpoint
  • GET /api/useraccounts/me - User profile endpoint

Testing Instructions

  1. Login Flow: Navigate to /login and sign in with credentials
  2. Protected Routes: Try accessing / without logging in (should redirect to login)
  3. User Menu: Check header for user menu with logout option
  4. Token Refresh: Wait for token to near expiry or manually test refresh
  5. Logout: Use user menu to logout and verify redirect to login
  6. Persistence: Refresh page while logged in (should remain authenticated)
